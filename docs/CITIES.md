# Города мира: слой для сценария 2010 года

Добавлены **9 793 городских центра** из полного набора GHS Urban Centre Database R2024A V1_2, у которых есть оценка населения за 2010 год. Весь слой входит в сборку; отбора по известности, стране или игровому размеру нет. Это подготовка данных для мода, а не работающий импорт в Age of Clicks.

## Что именно считается городом

GHSL определяет urban centre по плотности населения и размеру связного скопления ячеек: обычно не менее 1 500 человек на км² и 50 000 жителей суммарно. Такой центр может включать несколько муниципальных городов: например, Москва и часть соседних городов представлены одной агломерацией. И наоборот, в отдельных случаях одна муниципальная территория может содержать несколько центров.

Поэтому этот слой **не является списком всех юридически существовавших городов мира**, не включает все малые города и не гарантирует присутствия всех столиц. Имена внутри списка городов агломерации не размножаются в фиктивные города с одинаковыми координатами и населением.

## Историческая привязка

- Население берётся только из `MT_POP_TOT_2010`; это модельная оценка агломерации, не обязательно результат переписи и не население на 1 января.
- Точка получена внутри геометрии `GHSL_UCDB_MTUC_2010_GLOBE_R2024`, а не из современных координат. Это репрезентативная точка городской территории, не точное местоположение ратуши. Входная проекция ESRI:54009 преобразована в WGS84.
- Записи без населения за 2010 год исключаются: 1 893 из 11 686 исходных записей. Это означает отсутствие в определении urban centre для этой эпохи, а не отсутствие самого населённого пункта в 2010 году.
- `urban_first_epoch` и `urban_last_epoch` — эпохи обнаружения в модели урбанизации, не дата основания или уничтожения города.
- Принадлежность странам основана на исходном атрибуте страны с правками сценария. В частности, Южный Судан → Судан, Пуэрто-Рико → США, зависимые французские территории → Франция. Кюрасао на 1 января 2010 года входил в Нидерландские Антильские острова; в выбранной модели зависимые территории относятся к NLD.
- Если исходная страна отсутствует, используется попадание точки в полигон карты сценария. Точки не притягиваются к ближайшему берегу: если однозначного попадания нет, страна остаётся неизвестной.

## Названия и неполные записи

Исходные названия GHSL относятся к **2025 году**. Они сохранены в `source_name_2025`; имена всех городов ещё не прошли историческую проверку. Проверенные правки на начало 2010 года задаются в `data/cities.json` по стабильному ID и ожидаемому исходному имени. Например: Днепропетровск, Днепродзержинск, Кировоград, Порт-Элизабет и Бангалор. У каждой такой правки есть ссылка на источник.

В слое 277 записей с отсутствующими или повреждёнными исходными названиями. Для них используется техническое имя `GHSL urban centre <ID>` и статус `missing_or_damaged_source_name`, а исходный текст сохранён. У четырёх записей страна пока неизвестна: `country_tag: null`. Они остаются в слое и не получают вымышленных названий или владельцев. Точное состояние отражает `dist/cities_2010.report.json`.

Основные поля: `id`, `name`, `name_ru` (только там, где задан), `country_tag`, `population_2010`, `area_km2_2010`, `name_status`, `country_assignment`, `geometry_epoch`, `point_method`. Геометрия GeoJSON — Point в порядке долгота, широта. Пустые значения в CSV соответствуют `null` в GeoJSON.

## Повторный импорт

Обычная сборка `python tools/build.py` не требует сети и пакетов. Для обновления сокращённого первоисточника нужен Python 3.12 или новее и GIS-зависимости:

```sh
python -m venv .venv
.venv/bin/pip install -r tools/requirements-import.txt
# Скачать MTUC V1_2 по source_url из provenance.json, например в /tmp/ucdb-mt.zip.
.venv/bin/python tools/import_cities.py /tmp/ucdb-mt.zip
python tools/build.py
python -m unittest discover -s tests -v
```

Импорт использует только именованный GeoPackage из архива. Некорректные геометрии проходят `make_valid`; их ID записываются в provenance. Это исправление нужно для получения точки и не меняет опубликованные оценки населения. Сам большой архив не хранится в Git. При смене версии нужно отдельно проверить схему, контрольные суммы, исторические правки и изменения координат.
